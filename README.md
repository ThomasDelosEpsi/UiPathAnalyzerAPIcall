# UiPath Analyzer API Call

Page web autonome (fichier HTML unique) qui calcule/analyse la consommation d'appels API UiPath : import de fichiers, visualisation via graphiques (Chart.js) et fonctionnalités assistées par IA.

## Stack

- HTML/JS statique (aucune installation nécessaire)
- Tailwind CSS, Chart.js, JSZip, Font Awesome (via CDN)

## Usage

Ouvrir `Calculateur API UiPath.html` directement dans un navigateur.
